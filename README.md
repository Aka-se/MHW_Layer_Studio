# MHW Layer Studio

一个不依赖 Blender 操作的《Monster Hunter: World》MOD3 分层工具。它用于给现有
Mesh 设置 visibleCondition / Group ID，并生成适配
MHWI-VisualControllerExtended 的血量规则。

## 当前功能

当前版本为 0.6.1：拆分成组后的模型点选固定为“第一次选整组、再次点同一处选成员”，旧项目无法再误关组选择；同时保留 0.6.0 的可选“手动分层 / 随机战损”、拆分、分配、贴图和安全导出流程。默认仍使用手动分层，不会自动改写现有模组。

### 可选随机战损（0.6.0，游戏验证待完成）

顶部工具栏常显“手动分层 / 随机战损”，不增加工作区高度。“战损设置”中先将身体、皮肤等标为“基础 · 永不隐藏”，再点“其余参与随机”，也可逐组选择参与或恢复默认。标记不修改手动 Group；未显式标记的 Group 0 默认受保护。已有独立子组作为完整单位，父组不合并子组；组内有基础成员则整组受保护。需要联动的LOD版本请先加入同一部件组；未成组的Mesh各算一个单位。

每套装单独计算：每下降5个百分点，隐藏数量为 `可随机组数 × 当前已损失的5%阶段数 ÷ 20`，向下取整。20组在80%时隐藏4组，回血至90%恢复其中2组，再降至80%从当前可见组中重新抽取2组。剩余隐藏组保持稳定，不在每帧重抽；回满后再损伤可出现新组合。组少时不保证每5%都多隐藏一组。基础模型不参与预算，编辑器预览与游戏分别随机。

第一次开启随机模式后，ZIP/文件夹导出会自动给需要控制的Mesh分配独立ID，并写入 `nativePC/plugins/MHWLayerStudio-<标识>.ini`。模型几何、原手动层级和保护标记保留；原层级写入编辑信息，重新打开可继续编辑。切换模式后导出/覆盖保存并更新该配置，游戏内Ctrl+F5重载；两种模式使用同一份控制ID模型，不需要重新拆分。仍只用手动模式的旧流程保持原导出方式。

双模式模型需要 **MHWI-VisualControllerExtended 1.5.0-random-trial.1 或更新版**，配置文件与DLL放在同一插件目录。编辑器安装包不自动覆盖游戏插件或安装示例模组。单独MOD3无法连同nativePC配置导出，请改用完整文件夹或压缩包。自定义Group需要有对应隐藏阈值才能导出双模式，以免丢失原手动行为。读取已配置游戏目录时会避开其他清单占用的ID；游戏加载若发现ID冲突，会记录日志，冲突模型保留可见，不能据此判断已兼容。

大剑试用版同样驱动双模式衣装百分比：普通/强蓄只有三级蓄力扣5个百分点，真蓄两段各5；最后一次有效触发5秒后每秒恢复2点（每5秒10点）。真实HP不变。命中/砸地信号仍为实验检测，随机功能的实际游戏效果需另行验证。

新项目格式12、导出编辑信息格式4；保留旧格式读取。双模式包中的 `.mhw-layer-studio/editor.json` 保存原手动层级及基础保护信息，请保留用于后续编辑。

### Windows Num Lock 与点击选择修复（0.5.20）

开启小键盘 Num Lock 后，普通点击仍选择表面部件及其所属组；再次点击同一部件才进入组内成员。只有真正按住 Alt 时才穿透选择内部部件。修复旧版将 Windows 的 Num Lock 状态误认成 Alt、从而跳过表面及组选择的问题；主视图、拆分预览和空格临时着色共用正确的按键判断。Num Lock、Caps Lock、Scroll Lock 可正常保持开启。

模组库读取复用 Windows 目录枚举提供的文件属性，跳过无关贴图与辅助文件的额外属性查询。索引保存在本地用户数据目录，重启程序后也先显示上次成功读取的列表，再自动检查各级目录、盒子信息及压缩包的变化；只重新读取新增或变化的条目。新增、移除、重命名及盒子状态以更新结果为准。“读取 / 刷新”可以主动检查。搜索直接筛选已读取的名称和路径，复用列表行，不会每输入一个字就重建整张表。索引损坏时自动重新读取；中途取消不保存不完整索引。

读取状态使用醒目的蓝底深色加粗文字和进度条，显示检查数量、已复用及重新读取项数；完成后变为绿色，失败时给出红色提示。模组库、自定义阈值、名称备注、颜色图 / UV、按材质成组、导出确认、拆分及附件关联窗口统一相对所属窗口居中，并限制在所属显示器可用范围内。原生文件选择和提示框明确传入所属窗口，具体摆放由 Windows 管理。

### 默认四档与游戏配置位置（0.5.19）

默认 Group 60 / 61 / 62 / 63 分别在血量不高于 80 / 60 / 40 / 20% 时隐藏，高于阈值时恢复。Group 63 是新增的第4层；只有已分配到该 ID 的部件受 20% 档位控制，不会自动给其他部件分配 ID。旧格式项目或模组若使用原默认 80 / 60 / 40，会补上 20% 档；自定义阈值保留。新版保存后明确删除第4层的三档配置，再打开仍保持三档。

编辑器预览与游戏插件分别读取配置。导出的 `MHWLayerStudio_health_rules.ini` 是规则片段，需合并到实际加载插件同目录的 `nativePC\plugins\MHWI-VisualControllerExtended.ini`，替换同 ID 的旧分层规则。改游戏根目录中的同名 INI、或只修改 MHW Box 的源文件，并不代表插件目录的文件已同步。写入游戏配置前备份，游戏中按 Ctrl+F5 或 `/vc reload` 重载，也可重启游戏。

项目格式 11、导出编辑信息格式 3，用于区分旧默认三档升级与新版主动删除层级。旧项目和导出包仍可读取，模型几何和原有 Group ID 保持。

### 外层优先点击（0.5.18）

普通左键按点击处的真实表面深度选择最靠近视角的部件。开启“其他部件半透明”后，已选中的内层仍可突出显示，但不会占住外层的点击命中位置。Alt＋左键用于穿透选择内部组件，同一位置可继续循环。主界面和拆分预览采用同样规则。

拾取使用点击点的三角面深度，保持当前贴图透明像素、血量隐藏、手动隐藏、装备部位和 LOD 筛选；不会把已经隐藏的组件作为普通点击目标。颜色和贴图模式、拖动时的低分辨率预览均支持。父组 / 子组选择规则保持：命中部件后先选对应单侧组，再次点击选择组内成员。

### 左右子组与共同父组（0.5.17）

“建议左右成对”改为“建立左右父组”：自动成组始终保留两个独立单侧组，勾选后额外建立一个共同父组。以 Kuroki-EX2 的腿饰为例，父组含 12 个部件，下设左侧和右侧各 6 个部件。左右名称按默认正视画面区分，旋转视图不会交换名称。关闭此选项仍可得到独立单侧组，不建立父组。

拆分预览和主列表都直接显示父组 → 子组 → 成员。点击模型默认选择单侧子组，再次点击同一位置选择其中一个成员；从列表选择父组可同时选中两侧。子组可分别分配 Group ID，父组分配会统一修改所有成员；两侧层级不同时，父组显示“混合”。每个 Mesh 只属于一个独立子组，父组只引用子组，没有额外的游戏 Group ID 或继承规则。

手工建立父组：在“按部件组”列表中按 Ctrl 选择至少两个尚未归入父组的独立组，从右键菜单或右下“管理”中选“将所选组建立父组…”。解散父组会保留子组及其成员和层级；重命名子组会更新父组引用。向已有组加入成员仍不强制展开分组。当前支持一层父组，子组只属于一个父组。

父子关系支持撤销 / 重做，并保存在项目、ZIP、文件夹及单个 MOD3 的编辑信息旁文件中。项目格式升级为 10、导出编辑信息为 2，仍可打开旧项目和旧导出包；新父子关系需用 0.5.17 或更新版本继续编辑。已有手工组默认保留，需要重新分析时主动选择“重新整理已有组”。拆分本身仍依据空间和网格连通关系，骨骼用于拆分后的成组。

### 完整局部组件成组（0.5.16）

自动成组先检查同文件、同材质、同 Group、同精度内的小件。如果每个小件都至少有 90% 的权重受同一骨骼控制，三角面之间能按当前聚合距离相连，且整体最大跨度不超过模型高度的 18%，则先组成完整局部组件。这样绑带、扣环和中间连接条可以作为一套，而不是分别寻找最近主体。该规则只整理已有独立部件，不切割表面，不修改骨骼或权重。

默认勾选“建立左右父组”，对应单侧组件会在形状与位置对称时归到共同父组，两个单侧子组继续独立保留；取消后不建立父组。Kuroki-EX2 的原 wst / Mesh 1 中，腿部这套装饰包含每侧 6 个部件，父组同时选择双侧共 12 个部件。鞋子仍独立。骨骼未知、权重混合或不相连的部件继续使用原来的主体与附件核对规则，不因同材质强行合并。已有手工组默认保留；需要重新分析它们时须主动勾选“重新整理已有组”。

### 按表面距离关联附件（0.5.15）

自动空间成组改用三角面之间的实际距离核对近邻，包围盒只用于快速排除远处部件；不再仅凭包围盒相交判定相邻。骨骼、UV 和左右成对规则继续保留。几何仍按独立连接拆分，不自动辨认衣物语义。

已有独立 Mesh 时，先在主界面选择主体，再从右侧“部件组 → 管理 → 关联附近附件…”进入。此入口保留现有部件和手工组，不重新拆分或自动整理。也可在“拆分并成组”窗口中选择主体成员或组，点击底部“关联附件…”。

附件窗口显示在左侧列表区域，后方 3D 预览保持可见。单击候选行预览，双击切换勾选；可批量勾选推荐或全部勾选、取消。范围可调为模型高度的 0.1–5%，默认 1.5%，同时显示对应模型距离单位。改范围后点击“更新建议”，旧结果立即失效。

建议始终相对于原主体计算，不沿新附件继续扩张。默认仅查找同文件、同 Group、同精度及同材质部件；可主动包含其他材质，跨材质候选默认待确认。有骨骼支持、体量较小且没有邻近主体竞争的部件才默认勾选；UV 只作辅助。推荐也需要用户查看。

点击“确认加入建议组”只调整本次建议；回到预览窗口后，再点击“应用勾选建议”才更新当前编辑内容。Group ID 保持，支持整步撤销 / 重做；取消附件窗口或外层预览不修改当前模型。

### 遮挡部件的选中反馈（0.5.14）

可见的选中部分使用黄色实线和轻微填色，被其他部件挡住的选中部分使用橙色虚线和轻微填色。从列表选中内部部件也能看见其轮廓；内外多个部件同时选中时分别绘制，不再只显示最外圈。

普通左键沿用最前方部件的选组 / 成员操作。需要直接选择内部部件时，在模型上按住 Alt 点击左键，首次选下一层，再在同一位置连续 Alt 点击可循环切换。穿透选择直接选单个 Mesh，Ctrl / Shift 可叠加多选。鼠标离开该位置或改变相机后重新开始。

血量隐藏、手动隐藏、关闭的装备部位及当前不显示的 LOD 不参与透视高亮和穿透选择。启用贴图透明时，透明像素也不参与。主预览和拆分预览使用相同高亮及穿透选择逻辑。

### 视图导航（0.5.13）

- 滚轮围绕鼠标位置缩放，放大局部时不必反复平移；缩放到上限或下限后不继续偏移。拆分预览采用相同方式。
- 选中部件后开启隔离，自动适配所选；退出隔离恢复进入前的旋转、缩放和平移。隔离期间继续旋转或换选部件，也不覆盖进入前的记录。“显示全部”仍主动恢复整体观察。
- F 聚焦后绕所选部件旋转。中键双击模型可将所指部件设为旋转中心，所指部件属于当前选择时使用全部所选的中心；设中心不改变当前画面位置、缩放或选择。随后右键拖动旋转。拆分预览同样支持中键双击设中心。
- 点击预览区后按住空格临时查看独立部件色，松开恢复当前选用的着色；切换到输入框或其他窗口也会恢复。原着色选项不改变，临时着色不写入项目。拆分预览中按住空格可临时从贴图切到部件色。没有增加悬停名称。

### 选择与加入组（0.5.12）

右侧分配区和模型左上角明确显示整组、组内单个成员或多选状态；单个成员显示自定义名称（如已填写）及实际所属组，跨套装组标明当前套装与全组的成员数量。重复点击模型仍按首次选组、再次选组内成员操作。

右下“加入组”和列表右键“加入部件组”使用相同菜单，显示各组成员数和当前选择的归属；当前组置灰，避免无效重复加入。最近使用的最多 5 个目标组优先显示，其他组沿用主列表的上下顺序；最近目标仅用于本次打开的模组。加入仍支持撤销，目标组保留原先的展开状态。

### 保存与导出（0.5.11）

导出和覆盖成功后直接在底部状态栏显示保存位置，覆盖时同时显示备份位置，无需再关闭成功弹窗。覆盖确认、失败提示和导出前修改清单继续保留。

ZIP / RAR / 7Z 和单个 MOD3 按来源分别记住上次成功导出的位置及文件名，重启软件后继续使用；首次导出另一个模组沿用最近的导出目录，但使用该模组自己的名字。默认名称只保留一次 _layered 后缀。取消或导出失败不会改变记忆；选择已有文件仍须确认覆盖并自动备份。

### 加入组与保存快捷键（0.5.10）

右下“部件组”区域新增可见的“加入组”菜单按钮。先从模型或列表选择成员，点击按钮选择目标组；目标列表沿用主列表的上下顺序。选择目标不会先切换当前选中的成员，加入保留原 Group ID，目标组不强制展开，支持撤销 / 重做。列表右键“加入部件组”继续保留。

Ctrl+S 按当前来源处理：ZIP / RAR / 7Z 导出 ZIP，文件夹确认后先备份再覆盖保存，单个 MOD3 导出 MOD3 副本。Ctrl+Shift+S 始终另存副本。保存分层项目仍从“打开”菜单明确选择。覆盖确认、修改清单、自动备份和导出重读校验继续保留；连续按保存不会叠加核对窗口。

### 拆分窗口尺寸（0.5.9）

拆分并成组、LOD 成组和跨 LOD 同步窗口默认至少使用 1480×880 的内容区域；主界面更大时相应加大。在主界面所在显示器中相对主窗口居中，按该显示器的可用范围限制尺寸和位置，避开任务栏。小屏幕自动缩小，保留底部操作区；仍可手动调整窗口大小。

### 模组库路径（0.5.8）

顶部点击“模组库”，选择 MHW Box 的 `Mods_582010` 或自定义模组库文件夹。也可直接粘贴路径并点击“读取 / 刷新”；选择 MHW Box 本身时自动使用其中的 `Mods_582010`。程序会记住路径，下次打开无需再次选择。

列表读取盒子 `info.xml` 的真实模组名称和启用状态，打开相应模组的 `files` 文件夹，不会一次加载整个模组库。启用状态仅供查看，不改变盒子的开关。普通文件夹和 ZIP 优先列出包含 MOD3 的模组；RAR / 7Z 在打开时检查。输入名称或库内路径搜索，双击模组或选中后点击“打开所选”。新增或删除模组后点击刷新。

模组库入口不会放弃当前未保存的编辑内容，实际打开另一个模组时沿用原有确认。路径设置只管理快速打开的来源，不修改游戏目录、盒子信息或原模组，也不影响“游戏资源目录”的贴图读取设置。模型目录仍按原流程确认覆盖或另存。

### 0.5.7 预览和选择修复

支持在普通颜色槽为空时读取自发光颜色槽中的彩图，包括 Milltina Peridot 的 Costume、Body、Face、Hair、A8、B8、HALO 和 R。仍只预览彩图，不模拟游戏发光 Shader；已有普通颜色图优先。颜色绑定参考 [MRL3 贴图槽定义](https://github.com/AsteriskAmpersand/Mod3-MHW-Importer/blob/master/mrl3/maptype.py)。没有小尺寸 mip 的大贴图也缩到预览尺寸缓存，源贴图保持不变。

没有选中部件时，分层按钮保持原生边框、正常可读文字，辅助提示为“先选择部件”。点击只在状态栏提示选择，不修改模型。选中后恢复分配效果提示。

### 自定义层级数量和隐藏比例

默认四层使用 Group 60 / 61 / 62 / 63，对应 80 / 60 / 40 / 20。血量区直接点击“自定义隐藏阈值”，可修改百分比或增加、移除层级；右侧立即显示对应分配按钮，分配到对应 Group 的部件才受其控制。基础 Group 0 不参与血量模拟。

支持 1–32 个规则层级，Group ID 为 1–65535，不能重复；百分比为 0–100 的整数。层数和比例随项目及导出模组保存，预览、刻度和规则导出使用同一份设置。已有项目和模组保存的自定义规则会保留，需要统一新版默认时在此窗口点击“默认 80 / 60 / 40 / 20”再应用。删除规则不改 Mesh 的 Group ID，该 ID 在预览中变为未映射；已安装的游戏规则也应相应更新。

导出血量规则后，首次添加到插件 INI；更新时替换本工具旧的分层 Rule 段落，避免反复追加同一组规则。游戏文件不会被此设置窗口直接改写。新项目格式为 9，兼容读取版本 1–8；含新增层级的项目和编辑信息应使用新版编辑器打开。

### 连续分层操作

左侧选择部件，中间观察模型，右侧分配层级。血量滑条固定在模型下方，默认开启模拟：调到 70%，点击部件或整个部件组，再分配装饰层，模型立即隐藏；在同一血量改成护甲层则显示。分配保持血量、选择和视角，可直接继续选择下一块或撤销。分配按钮显示配置阈值以及此刻分配后的血量显隐结果；隔离、部位开关或手动隐藏仍可能影响实际可见性。

滑条上方可输入 0–100 的整数；点击轨道立即跳到点击位置，也可拖动。刻度与当前项目的隐藏阈值同步；阈值较密时保留所有刻度线并错开部分数字。滑条获得焦点时方向键微调 1%，Home / End 跳到 0 / 100。隐藏阈值通过血量区常驻的“自定义隐藏阈值”修改，右侧分配按钮显示当前项目的设置。血量等于阈值时隐藏，高于阈值时恢复。修改规则后仍需导出规则并更新游戏实际加载的插件 INI。

有命名部件组时，列表默认按组浏览，点组选择当前套装内全部成员。默认只显示部件名称、层级和当前显隐；“列”菜单可显示材质、备注、所属组、原始 Group 与 LOD，列宽可拖动，列的选择随项目保存。隐藏部件仍留在列表且保持选择，区分“因血量隐藏”“手动隐藏”“其他精度”“部位关闭”及“隔离排除”，可继续修改。

顶部常驻打开、导出模组/压缩包、覆盖保存、撤销和重做；项目打开与保存收在“打开”菜单，导出血量规则收在“设置”。覆盖保存仍核对修改、确认目标并自动备份，未跳过原有保护。导出的模组已保存部件组、名称及备注，通常直接导出或覆盖即可继续编辑。

点击“拆分 / 自动成组”展开拆分并成组、材质成组、LOD 成组及跨 LOD 同步，面板保持展开直到再次点击。右侧“部件详情”按需展开，查看材质、贴图、骨骼、原始信息或编辑名称和备注。右侧内容较多时可滚动查看。左侧右键可新建组、加入指定组、移出、重命名或解散组。模型上方常驻分层、独立部件、材质、贴图四个着色选项。标准视角、精度和半透明收在“视图”，贴图资源目录收在“设置”。

预览工具栏最左为“隔离”，点击再次退出。选中部件或组后，可用“隐藏所选”快速观察移除后的效果；隐藏后同一按钮变为“显示所选”，取消临时隐藏。血量、视角、选择及 Group ID 保持，恢复后仍按当前血量和精度显示。层级按钮第一行为主要信息，第二行的小号灰字提示当前血量下的分配效果，两行均可点击，也可用键盘确认。

### 拆分入口与按组选择（0.5.6）

- 拆分并成组：在副本中拆开不相连的几何，再按空间位置、骨骼 / UV 建议分组；日常优先使用此入口。默认聚合程度为“常规”。
- 跨 LOD 同步拆分：以已整理的高精度部件为基准，核对并重组低精度完整几何块，使同一组在不同精度同步控制。
- 材质成组：只把现有同材质 Mesh 归组，不拆分几何；同材质可能包含多件衣物。
- LOD 成组：将对应的各精度版本整体归组，不细分衣物。

主视图第一次点击组内任一 Mesh 会选择当前套装中的整个组，再次点击同一部件选择该成员；继续点击保持成员选择，点击另一部件重新按组选择。Alt＋左键用于穿透并直接选择内部单个部件。Ctrl / Shift 可多选组，再“新建组”重新归组；列表中仍可直接选择具体成员。新建组与移入组不会强制展开目标组，原先手动展开的目标保持展开。

空间建议组增加头部、颈肩、躯干、手臂、手部、腰部、大腿、小腿和脚部的位置提示，保留所属文件部位、材质与编号。建议组、主列表的部件组和文件内成员按模型高度从上到下排列，旧手工名称不改写。拆分子部件没有别名时也显示位置提示。这是按模型坐标估计的区域，不是衣物语义识别；特殊姿势或跨部位衣物仍需预览核对。

### 跨 LOD 同步拆分（Garon 腰部试点）

在左侧选择一个 MOD3 文件或其中的 Mesh，在“拆分 / 自动成组”选择“跨 LOD 同步拆分”。逐个文件处理，在同材质、同当前 Group 的对应 LOD 家族内，以现有最高精度 Mesh 分别作为控制基准。最高精度仍含多个衣物时，可先使用“拆分并成组”及预览辨认，再尝试同步。

低精度先找不相连的完整几何块，比较这些块与高精度三角面的距离；采样选择候选后核对该块的全部使用顶点。候选之间差别不够明确、范围偏差过大或骨骼影响冲突时保留待确认。UV 对应偏差作为核对信息，不因贴图接近强制归入。此版本不切割三角面，也不自动切开仍连接着多个衣物的低精度表面。

低精度中对应同一高精度基准的块重组为一个 Mesh，保留每个原始三角面一次，原始顶点记录（法线、UV、权重等）、材质、LOD 和阴影标志保持。无法确认的完整块独立保留，不遗漏或强行分配。

展开控制组和待确认块，切换精度查看。选择待确认块后，目标下拉框定位到候选组；勾选“同时看候选”，以黄色轮廓的待确认块和淡化的高精度基准对照，点击“聚焦”居中。确认后点击“移入该组”。如果低精度块确实包含多个高精度部件，可把相关控制组和该块另建为一个共同控制组；不能独立控制的关系不要强行拆开。所有待确认块须归入带高精度基准的已勾选组，才能应用同步拆分。

确认前只计算副本；应用不改 Group ID，再在主列表给整个控制组设层级。Ctrl+Z / Ctrl+Y 整批撤销 / 重做，临时隐藏状态随新编号对应恢复。默认跳过已有部件组，需重新整理时勾选对应选项。

Garon 的 `f_wst029_0001.mod3` 试点有 4 个高精度 Mesh、5 个合并的低精度 Mesh。默认提出 4 个控制组和 3 个最远距离待确认块，文件从 9 个 Mesh 变成 27 个。核对待确认块后，4 个控制组可以分别设置 Group，包含各精度的对应 Mesh。测试副本在工具内的 6 个 LOD 显隐及回血恢复、轮廓覆盖、导出重读、撤销和项目恢复均通过；游戏内远近切换仍需实际验证，示例副本不代表所有候选已自动正确识别。

拆分兼容性补充：原包中已分配包围盒记录之后的多余记录和顶点前填充完整保留；分配记录不足、索引异常或未支持的附加缓冲区仍拒绝重建。参考 [MOD3 包围盒结构及顺序](https://github.com/AsteriskAmpersand/Mod3-MHW-Importer/blob/master/mod3/Mod3Mesh.py)，不通过丢弃未知数据绕过校验。

新项目格式为 9，保存确切三角面分区，重新打开不重新猜测对应关系；兼容读取旧版本项目。导出 ZIP 已包含重组的模型及编辑信息，重开不会重复拆分。

### 骨骼 / UV 辅助空间成组

“拆分与空间成组”默认使用“常规”聚合程度，并开启“骨骼 / UV 辅助空间成组”，可关闭对照旧结果。范围仍由“保守 / 常规 / 宽松”控制，分别采用套装纵向高度的 0.8%、1.5%、2.5% 作为包围范围间距上限；骨骼相似不会扩大这个距离，也不会通过小碎片逐步扩大主体归属范围。

在同文件、同材质、同 Group、同 LOD 的附近候选中，工具比较实际使用顶点的骨骼影响分布。明显不同的骨骼影响阻止自动归入；同时靠近多个主体且骨骼影响有明显差别时，用它区分候选。左右镜像部件结合形状和位置建立共同父组，允许左右两侧使用不同的骨骼编号，单侧子组保持独立。

首版 UV 辅助比较主 UV 的范围间距，用于给骨骼和空间仍有歧义的部件提示候选。UV 接近或共用不能单独决定归属，因此这类建议保持待确认，不自动加入主体。跨出单图范围的重复 UV 暂不用于候选比较。这里的“骨骼影响重合百分比”表示分布相似程度，不是衣物识别成功率。

展开建议组，成员的“分组依据”列显示骨骼编号及影响、与候选主体的骨骼重合程度和 UV 间距；右侧随选择显示骨骼 / UV 范围。主编辑器信息栏也显示权重读取状态和主要骨骼影响。开关随项目和导出模组的观察状态保存；组名和成员照常保存。

常见 4 / 8 骨骼权重读取参考 [MOD3 顶点格式](https://github.com/AsteriskAmpersand/Mod3-MHW-Importer/blob/master/mod3/Mod3VertexBuffers.py)。未知布局、特殊标志或较大的负余数不参与骨骼判断，界面显示原因。仅创建分析副本，不重写权重、UV 或原始顶点数据；几何拆分仍采用原有连通性方法，不按骨骼直接切开相连表面。

EX2 腰部 Mesh 1 仍拆出 31 个子部件：新增骨骼依据后，袖口 Mesh 9 / 10 可分别归到 Mesh 4 / 3 的主体组，待确认由 6 个减少为 4 个；连接条 Mesh 25–28 提供 UV 候选，但保留待确认。简单“LOD 自动成组”继续保留各精度整体，需分别控制合并的低精度部件时使用新入口“跨 LOD 同步拆分”。

### 同一部件的不同精度（LOD）自动成组

原生外观常在同一 MOD3 中保留多套不同面数的版本，供游戏随观察距离选择。预览默认显示“高精度”及通用 Mesh；“视图 → 观察精度”菜单可切换其他版本或“全部版本”，只影响观察，不改游戏 LOD 字段。列表新增“精度 / LOD”列，右侧信息显示原始掩码。单独选择当前精度中不可见的 Mesh 时自动切到能看见它的精度。

点击“LOD 自动成组”，选择所选 Mesh、所在文件或当前套装范围。按同文件、同材质、同 Group 以及空间范围的唯一对应关系提出组，选择一个版本也会纳入其对应版本；不跨套装、不改变模型几何。展开成员、切换精度核对后应用，再选该组设置 Group ID，会统一修改所有成员。命名组可撤销、保存项目、随导出 ZIP 恢复。

Garon 的腰部包含 4 个高精度 Mesh，而后续精度每级合成一个腰部 Mesh；简单成组把这 9 个 Mesh 作为一个控制组，提示“低精度合并多个高精度部件，需一起控制”。要分别设层级，请使用“跨 LOD 同步拆分”核对完整几何块。范围对应只是建议，不能识别衣物语义；重叠且无法唯一匹配的版本保持待确认，通用掩码 65535 不作为重复版本关联。

“拆分与空间成组”默认勾选“关联对应 LOD；保留各精度整体”：LOD 先关联并保留整体，通用 Mesh 才按独立几何拆分。已有手工组默认跳过，需重新整理时勾选对应选项；取消 LOD 关联后可以分别拆分各精度，但空间建议仍按 LOD 掩码隔开，不混合精度。若之前已导出大量碎片，建议用原包重新生成 LOD 分组，另存副本对照。

### 拆分与空间成组

选择原 Mesh、文件标题或已有子部件，在“拆分 / 自动成组”点击“拆分并成组”。可处理所选 Mesh、所在文件或当前套装；“全部套装”视图的套装范围包含所有套装。默认先按接缝容差分开不相连的几何，已拆分的子部件也可以直接分析。相连表面保持整体，不能用此功能切开同一连续表面。

所有拆分与分组先在内存副本中计算，确认前不修改当前模型，不写源文件。分析在后台运行，可取消。无法安全拆分的 Mesh 保持整体并提示原因。默认跳过已在手工组中的 Mesh；勾选“重新整理已有组”才将范围内的已有成员纳入分析，范围外成员保持。自动建议按“文件 + Material ID + Group ID”分别处理，不混合不同文件 / 套装 / 现有层级。

“保守 / 常规 / 宽松”改变相邻部件的距离容差，按当前套装模型的纵向高度归一化。同骨骼的高置信局部组件先按上方规则整理；其余主体聚合要求彼此均接近、处于同一区域并且范围相似，避免靠一串小碎片将远处衣物连成一组。其他小部件只参照固定主体范围，靠近多个主体或离主体较远时标为“待确认”，默认不勾选。“建立左右父组”按 X 镜像位置、范围与面数相似性给出父子组建议，不意味着已识别衣物名称。

展开每个建议组可查看所有成员、原 Mesh、当前 Group 和材质；点击组或成员，用右侧黄色高亮、淡化上下文、“只看所选”和“聚焦”辨认。右侧支持旋转、缩放和颜色贴图。双击组名前的勾选标记或用“勾选 / 取消所选组”调整要应用的组；可以改组名、将所选成员另建组、移入其他建议组。手工调整只改变部件组成员，不合并几何。

选项改变后请重新点“生成建议”。点“应用勾选建议”才把整批拆分与已勾选的命名组应用到编辑器；未勾选的子部件仍独立保留，原来无组的保持未成组，原有手工组未被选中的成员保留。Group ID、材质、顶点记录、名称与备注保持；需要分层时，再在主列表选择组并分配 Group ID。Ctrl+Z / Ctrl+Y 一次撤销 / 重做整批拆分与成组，项目及导出模组会保存最终结果。

该功能按通常的 MHW 模型坐标 Y 向上、X 左右和静态模型范围推测空间关系，并可用骨骼 / UV 辅助比较，没有识别贴图语义。比如 EX2 腰部 Mesh 1 的 31 个子部件可提出鞋子与上部衣物分开的建议，但附近、重叠或真正相连的部件仍需人工检查。建议名称仅描述“下部 / 中部 / 上部”等位置，避免把猜测直接写成衣物类别。

### 流畅观察与血量模拟

连续旋转、平移或缩放时持续更新画面；拖动时预览最长边最多以 480 像素绘制并放大显示，停止约 160 毫秒后恢复窗口原尺寸。保留全部三角面，不抽面，不修改模型。预览降低分辨率时仍可按实际显示画面选择 Mesh。

血量数字即时更新，只有跨过当前可见 Mesh 的隐藏阈值时才重新绘制模型；同一阈值区间内以及关闭模拟时不会反复重画。切换文件、套装、选择或修改模型后，旧预览不会覆盖新的画面。首次使用颜色或贴图预览仍需要后台初始化绘制组件。

### 从游戏中自动补齐贴图

点击预览区域下方“游戏资源目录”，选择包含 `chunk` 文件夹的 Monster Hunter World 游戏安装目录。首次设置后自动切换“贴图”预览；以后启动自动恢复目录。程序优先使用模组自带及共享目录中的图片，缺失时按 MRL3 引用在游戏资源包中查找，更新编号较大的 chunkG 包优先于旧包。

安装包自带独立开源解压组件，不需要另找 Oodle DLL，不需要联网下载或将整个游戏解包。首次只建立贴图文件索引，并读取实际用到的颜色图；后台执行，状态栏显示查找进度。游戏目录只读，缓存位于 `%LOCALAPPDATA%/MHW Layer Studio/game-textures`，不会写入游戏或导出的模组。缓存损坏会重新读取，游戏包更新后采用新的缓存；重新打开模组或重新选择目录刷新当前已经显示的图片。

游戏目录设置保存为编辑器偏好，也随项目和模组观察状态保存。换电脑后若目录不可用，可重新选择。此功能支持冰原格式的 `chunkG*.bin`，不处理早期本体格式或高清资源包，也不模拟 Shader、染色、骨骼或物理效果；未找到 / 暂不支持的颜色图仍用分层色，并显示原因。灭尽龙 α / β 样本的 20 个材质已验证全部读到颜色图。

### 直接修改模组文件夹

点击“打开文件夹”，选择需要修改的模组目录（例如该模组的 `nativePC`），编辑后点击“覆盖保存”。先核对 Mesh 修改清单，再确认具体目标路径；确认默认选择“否”。原文件夹保存只写入有变化的 MOD3 和 `.mhw-layer-studio/editor.json`，贴图、MRL3 及其他未涉及文件保持内容和时间不变。这样不必反复导出、重新安装；游戏需重新加载外观才能看到更新。

每次覆盖前，在目标旁边的 `.mhw-layer-studio-backups` 中创建独立备份，保存被覆盖文件和目标清单。备份失败、重读校验失败或确认后文件发生外部变化时不覆盖；多文件写入失败会尝试恢复原文件，若无法自动恢复，会提示备份路径。备份的 `files` 目录对应原目录结构，可按 `manifest.json` 记录恢复。

覆盖原模组后自动重新载入，保留部件组、名字、备注、隐藏阈值与视图，清空撤销 / 重做历史。原模型基准已变化，已有分层项目需重新保存；旧项目仍有模型指纹保护，不会强行套用。只修改备注也可以覆盖保存，不会重写没有变化的 MOD3。

ZIP / 单个 MOD3 同样可以覆盖；单个 MOD3 同时备份其编辑信息文件。RAR / 7Z 首次仍需另存 ZIP，之后“覆盖保存”更新最近导出的 ZIP。对文件夹，“覆盖保存”始终写回当前打开的原文件夹。正常“导出模组”继续默认另存副本，选到已有输出时也会显示覆盖提醒。编辑压缩包本身不会更新游戏已安装的文件夹。

### RAR / 7Z 模组

“打开模组”可以直接选择 ZIP、RAR、7Z。安装包自带读取组件，无需另装 WinRAR 或 7-Zip。支持普通和整体压缩的 RAR4 / RAR5 / 7Z、中文目录；格式按文件内容识别，例如扩展名为 `.rar` 的 7Z 包也可以打开。RAR 分卷需全部放在同一目录并打开第一卷。加密包请先用密码解压为文件夹，再选择“打开文件夹”。

RAR / 7Z 仅作为输入，编辑后统一另存为 ZIP。原压缩包不覆盖；模型、贴图、材质及其他资源通过临时 ZIP 缓存读取，导出保留未修改文件的内容。命名部件组、备注与阈值随导出 ZIP 或项目保存。读取超过 8 GB 或不安全链接路径的包会提示改用普通文件夹。

### 修改隐藏血量百分比

打开模组后，点击血量区“自定义隐藏阈值”，分别修改各层百分比，例如将前三层改为 85 / 70 / 55。血量低于或等于对应百分比时隐藏，高于时显示；Group 0 保持基础层。支持撤销 / 重做、恢复默认 80 / 60 / 40 / 20，设置随项目和导出模组保存。分层按钮与血量模拟即时使用新值。

游戏内的阈值来自 VisualControllerExtended 的 INI，而非 MOD3。更改后需重新“导出血量规则”，将新规则替换游戏实际生效的旧规则；不要再追加同一 Group 的旧规则。多个模组共用同一 Group ID 时会共用这套阈值。编辑器不会自动写入游戏目录。

### 看清部件组与成员

左侧列表方式可切换“按文件 / 按部件组”。已有分组的项目或模组默认按部件组展示，新建组或自动成组后也会切换；恢复项目时遵守保存的列表方式。按部件组展示“组 → 来源文件 → Mesh”，未归类的部件集中在“未成组”。每组显示当前套装成员数量，备注列显示当前 / 全组数量，Group 列显示统一 ID 或“混合”。

点击组名即可选中当前套装内全部成员，即使组处于折叠状态也可以分层、隔离、聚焦或隐藏。点击箭头或双击组行展开成员，再选择个别 Mesh 编辑。Ctrl / Shift 可选择多个组或成员，重复的 Mesh 不会重复操作。跨套装组仍只操作当前套装内成员，要编辑整个跨套装组时切换“全部套装”。

“查找部件组”按组名筛选，点击“清除”恢复；筛选仅改变列表，不修改分组或临时隐藏。每个 Mesh 的“所属部件组”单独一列显示。在文件列表中右键 Mesh，点击“定位所属部件组”，即可切到该组并选中、展开它。右键组还可展开 / 收起成员、隔离、聚焦、隐藏、重命名或用所选成员新建组。

### 调整列表列宽

在表头两列交界处拖动，可独立拉宽或缩窄列；拉宽不会挤压相邻列，超出可见范围后使用底部横向滚动条。双击表头边界自适应该列，或点击“自适应列宽”调整全部列。按材质成组的预览表也支持拖动和双击边界。

拖动列表与 3D 预览之间的分隔条可调整列表区域宽度。缩小窗口时三个区域按比例调整，列宽保留。列表方式、组名筛选、组的展开状态、整组选中状态、各列宽度和面板比例随项目及导出 ZIP 的编辑信息保存。旧项目缺少布局信息时使用默认设置，不影响分组或分层。

### 按材质自动成组

拆分后新子部件会自动被选中。在右侧“部件组”点击“按材质成组”，核对拟创建的组名、所属文件、Material ID、成员数量和现有 Group，再点击“应用成组”。例如 EX2 腰部 Mesh 1 拆出的 31 个子部件共享 EX2 材质，可一次归为一个组。

可选择所选 Mesh、所选 Mesh 所在文件或当前套装全部 Mesh。直接选择文件标题即可按整个文件操作，避免逐行选择上百个子部件。“当前套装全部 Mesh”包含当前套装的所有文件，不受临时隐藏或血量模拟限制；在全部套装视图中会处理全部套装，窗口有提示。

自动成组按“MOD3 文件 + Material ID”分桶，同名材质的不同文件、套装或不同 Material ID 不混在一起。默认只处理未加入命名部件组的 Mesh，保留已有手工分组。需要重新归类时勾选“重新整理范围内已成组的 Mesh”，预览显示移动数量与被替换的组数；移空的原组被替换，范围外成员及原有空组保持。名称冲突自动添加序号，不覆盖无关组。

成组只整理编辑器中的成员关系，不改变 Group ID、模型几何、贴图、别名或备注；整批操作可以 Ctrl+Z 撤销 / Ctrl+Y 重做。选择组后可隔离、隐藏、聚焦、批量设置 Group，或移出所选成员重新组成“鞋子”“外套”等。组名和成员随项目及导出的模组保存。

这属于初步归类：子部件继承原 Mesh 的材质，若鞋子与外套本来共用材质，会归入同一组；不会仅凭材质自动判断具体衣物名称，也不会把已经拆开的几何合并成一个 Mesh。

### 颜色贴图辨识

在模型上方的着色选项选择“贴图”，使用 MOD3 的 UV 和 MRL3 中的颜色图关联进行基础预览。支持常见 TEX 的 RGBA、BC1、BC4、BC5、BC7；使用较小 mip，首次切换需要初始化，模型在后台绘制。没有游戏 Shader、PBR 或骨骼动画。

颜色图优先按 MRL3 的 albedo 绑定识别，不要求文件名带 `_BML` / `_BM`；旧记录缺少绑定时仍可按常见名称识别。游戏默认 `null_white`、`null_black`、`null_gray_LIN` 缺失时使用对应常量色预览，提示未模拟 Shader 染色，不会生成或修改游戏贴图。只提供皮肤图的模组可通过“游戏资源目录”补齐游戏中的原版护甲颜色图。

优先使用模组自带贴图；“共享贴图目录”用于读取已解包的文件，“游戏资源目录”用于补齐 chunk 资源包中的图片。程序也会检查来源附近、当前磁盘常见 SteamLibrary 与 Steam 配置里的 nativePC 目录。缺图或未知 UV 格式使用分层色，右侧提示具体原因。

“指定颜色图”可给所选材质指定 TEX / DDS / PNG 等图片，仅用于预览，同一 MOD3 内使用该材质的 Mesh 一起更新。“查看贴图 / UV”可查看颜色图并叠加所选 Mesh 的 UV。透明区域默认关闭，因为某些材质的 alpha 用于其他用途；需要观察镂空时手动开启。共享目录和指定图片路径会随项目或导出的编辑信息保存，但外部图片本身不会被复制进模组，换电脑后可能需要重新指定。

### 随模组保留分组与备注

使用编辑器导出 ZIP / 文件夹后，会在 `.mhw-layer-studio/editor.json` 中保存部件组成员、名称、备注、原始 Group、拆分标签和观察状态；重新打开导出的模组即可恢复，不需要另外寻找项目文件。编辑信息位于 `nativePC` 外，MOD3 中的 Group ID 仍是游戏实际使用的层级。

单独导出 MOD3 时，会同时生成 `文件名.mod3.mhwlayer.json`，请将它与 MOD3 一起保留。删除编辑信息不会影响游戏分层，但会丢失编辑器名称与成组关系。打开时核对每个 MOD3 的 SHA256；模型被外部工具修改后不会把旧标签强行套到新 Mesh 上。导出的拆分几何不会被再次拆分。

### 名称与备注

双击表格的“显示名称 / 材质 / ID”单元格，为 Mesh 命名，例如左鞋、右鞋、衣领；双击备注列填写分类说明。也可以多选后点击“部件详情 → 贴图 / 名称 → 编辑名称 / 备注”，勾选需要批量修改的字段。多选编辑默认不勾选字段，避免清空不同成员已有的名称或备注；勾选后留空可清除对应字段。

名称为编辑器显示别名，原材质名、Material ID、MRL3 绑定和贴图路径保持不变，原名可在右侧信息区核对。名称和备注随项目及导出的模组保存。左侧部件名称和层级同时保留；材质列可从“列”菜单开启。支持撤销/重做；继续拆分时子部件继承标签，后续 Mesh 编号变化自动重映射。项目格式版本 9，兼容读取旧项目。

### 多套装模组

同一模组里的不同 `f_equip/plXXX_XXXX` 或 `m_equip/plXXX_XXXX` 自动识别为不同套装。左侧按“套装 → 装备部位文件 → Mesh”组织，套装下拉框可切换预览，默认只显示第一套，避免多个 body/wst 重叠。选择“全部套装（叠加查看）”可以跨套装选择与对比。

套装使用原目录编号显示，不猜测游戏中的 α/β 名称；不同可选目录和男女装备保持分开。当前套装与观察状态随项目保存。“显示全部”恢复当前套装的所有部件，保留套装选择。切换不会删除已有分层、拆分或命名部件组，导出仍包含全部套装。

跨套装命名部件组在单套装视图中只选择当前可见成员，并提示数量；要一次处理整个组，先切换“全部套装”。Skimpy Master Garon 样本已识别出四套、20 个 MOD3、143 个 Mesh。

### 命名部件组

多选 Mesh 后，在右侧“部件组”点击“新建组”，输入“鞋子”“外套”等名称。之后从下拉框选择组名即可选中全部成员，再使用分层、隔离、隐藏或聚焦按钮。使用可见的“加入组”按钮选择目标；支持重命名、移出所选、解散与撤销/重做。

每个 Mesh 属于一个命名部件组；加入另一个组会移出原组。组内 Mesh 拆分后，所有新子部件继承该组。命名和成员操作保留现有 Group ID，需要统一显隐时选择整组再分配 Group ID。

组名和成员随分层项目及导出的模组保存。游戏通过 Mesh 的 Group ID 控制显隐；部件组用于在编辑器中一次选择、分配多个 Mesh。兼容打开早期项目。

### 拆分后分层

1. 打开模组，选择一个 Mesh，例如 Kuroki-EX2 的 wst / Mesh 1。
2. 点击“拆分 / 自动成组 → 拆分并成组”，核对建议后应用。使用 0.00001 模型单位的接缝距离容差判断连通性，不修改实际顶点坐标，不自动识别衣物名称。
3. 使用独立部件着色、隔离和聚焦判断小块。Ctrl/Shift 多选左右鞋、装饰等需要一起控制的 Mesh，再点击同一个分组按钮。
4. 保存项目可以保留拆分与 Group 分配；Ctrl+Z 可以撤销拆分。导出为新的 ZIP 副本。

拆分保留原始顶点记录（UV、法线、切线、骨骼权重）、材质与原有保守包围盒。只支持不相连部分，不能切开连续曲面；遇到未支持的附加缓冲区会拒绝拆分。拆分导出已经通过本地数据校验，仍需用户在游戏中验证新 Mesh 的显隐、动画和阴影。

0.3.2 中 EX2 的 wst / Mesh 1 新拆分结果为 31 块，避免旧算法产生接缝处 1～8 个三角面的碎片。旧项目按原算法恢复，组名和 Group ID 不会被套到新编号上；要使用接缝修复，请先保存旧项目，再打开原始 ZIP 重新拆分。新项目格式记录拆分算法，兼容读取旧项目。

- 打开单个 .mod3、包含 MOD3 的模组 .zip / .rar / .7z 或文件夹。
- 将 helm/body/arm/wst/leg 放在同一个坐标空间中预览。
- 列表 Ctrl/Shift 多选，3D 画面 Ctrl 点击追加或取消选择；多选后批量设置 Group。
- 隔离所选、临时隐藏、显示全部、其他部件半透明；helm/body/arm/wst/leg 独立开关。
- 表面明暗和黄色所选外轮廓；按分层、独立部件或材质着色。
- 左键点击选择、中键拖动平移、右键拖动旋转、滚轮缩放；正面/背面/左右侧视角。
- 隔离时自动聚焦部件，F 聚焦所选，自动居中和重置视角；Windows 中文字体与 DPI 适配。
- 读取 MOD3 材质名称，通过 MRL3 名称哈希关联可能使用的贴图路径。无匹配时明确标为未知。
- 显示装备部位、Material ID、Group/原始 Group、顶点与三角面数量。
- 批量修改一次撤销/重做；保存和恢复分层项目、分组与观察状态。
- 设置基础层、内层、护甲层、装饰层或自定义 Group ID。
- 血量模拟默认开启，可关闭或使用滑块预览 40%/60%/80% 分层显隐。
- 导出前核对修改清单与二进制字段，导出后重读验证 MOD3/ZIP。
- 导出 VisualControllerExtended 血量规则。

仅设置 Group 时，程序只原位修改现有 Mesh 头中的16位 visibleCondition。
主动拆分时会重建 Mesh 表与顶点、索引缓冲区；不会自动切开连续曲面，也不会修改材质、CTC 或 CCL。

## 游戏内生效条件

编辑器是制作工具，游戏运行时仍需：

1. Stracker's Loader；
2. MHWI-VisualControllerExtended；
3. 编辑器导出的模组文件；
4. 将编辑器导出的规则追加到插件的 INI。

默认映射：

| Group ID | 层 | 显示条件 |
| ---: | --- | --- |
| 0 | 基础/原始 | 始终显示或交回游戏原逻辑 |
| 60 | 装饰层 | HP > 80% |
| 61 | 护甲层 | HP > 60% |
| 62 | 内层 | HP > 40% |

这些规则没有 LatchUntilReset，因此回血后会重新显示。

## 源码与发布边界

编辑器与游戏插件作为两个独立项目发布。编辑器安装包负责打开、拆分、分组、
预览和导出 MOD3；插件包负责游戏运行时的血量、随机战损和大剑命中逻辑。
编辑器会导出血量规则片段和随模组保存的随机战损清单，但不会导出全局
`[GreatSwordBurst]` 设置。

编辑器安装程序通过 `build_windows.bat` 或 GitHub Actions 构建；插件在独立仓库中
维护和发布。贡献约定见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 安全策略

- 压缩包默认另存为新文件；打开文件夹时可选择备份后覆盖保存。覆盖前必须确认，
  且备份成功后才写入。
- ZIP 导出会保留未修改条目的名称、内容和元数据。
- 文件夹另存会复制贴图、材质等所有配套文件；目标不能位于源文件夹内。
- 切换文件或关闭程序前，如有未导出修改会进行确认。
- 分层项目记录源 MOD3 的 SHA256，源模型改变时拒绝套用分组。
- 导出成功或保存项目后可以退出；“恢复原分组”可作为一次操作撤销。

## Windows 本地验证

运行 `.venv\Scripts\python.exe -m unittest discover -s tests -v` 检查二进制修改、
副本导出与血量阈值。根目录存在“暴雨魔女.zip”时会执行真实样本测试；缺失时
样本测试跳过，不应据此宣称真实样本验证成功。

运行 `.venv\Scripts\python.exe scripts\windows_smoke.py` 实际创建 Tk 界面，
向预览发送点击、拖动、滚轮事件，并验证降血隐藏、回血恢复和导出重读。
结果与模型预览图保存在 `validation-output`；这属于程序化界面验证，仍需人工
检查不同屏幕 DPI 下的布局与中文显示。安装包按当前用户安装，无需管理员权限。

预览在后台绘制完整三角面，不再通过丢弃三角面简化旋转；连续操作时仅显示
最新视角的结果。大模型帧率仍受软件渲染限制。支持基础颜色贴图，不模拟游戏 Shader 或骨骼动画。

`validation-output` 中的 body Mesh 0 / Group 60 副本仅用于验证流程，不能
直接视为已确认的装饰层方案。先在“仅显示所选 Mesh”中辨认部件，再决定分组。
默认血量规则覆盖 60/61/62/63；在“自定义隐藏阈值”中配置的其他 Group 也会生成对应血量规则，未配置的 Group 不自动加入。

## 游戏内验证

1. 保留原模组与插件 INI；测试副本和原模组不要同时启用。
2. 选一个确认属于装饰的独立 Mesh，设为 60，导出新 ZIP。
3. 将导出的血量规则追加到插件 INI 的副本。确认 Rule100–105 及 Group 60–62
   没有与既有规则重复；有冲突时先调整编号和对应 Mesh 的 Group。
4. 用模组管理器启用测试副本，游戏 `nativePC\plugins` 中保留插件 DLL 和匹配 INI。
5. 装备对应外观后检查 HP 81% 显示、80% 隐藏、回血至 81% 恢复。
   如使用其他两层，再检查 60% 和 40% 边界；新增第四层可检查 20%。

用户已确认 v0.1 的游戏分层正常。未拆分时仍只修改 Group 字段；v0.3 拆分会重建
Mesh 表、索引与顶点缓冲区，新模型仍需在游戏中检查显隐、动画和阴影。

## 推荐排查步骤

1. 打开 ZIP，选择一个 Mesh，勾选“仅显示所选”。它会自动居中放大。
2. 用左右侧或背面检查形状；看右侧材质名称、贴图路径和 body/wst 等所属部位。
3. 取消隔离，勾选“其他半透明”查看它与身体的位置关系。
4. 用“隐藏所选”观察身体是否缺口，再点“显示全部”恢复预览。
5. Ctrl/Shift 多选相关部件，一次分配到 60、61、62 或 63；Ctrl+Z/Y 撤销/重做。
6. 勾选“血量模拟”，拖动滑块检查显隐。临时隐藏和部位开关不会修改 Group。
7. Ctrl+S 按来源导出压缩包或备份后保存文件夹；需要另存项目时，从“打开”菜单选择“保存分层项目”。
8. 点击导出，核对每个 Mesh 的原始 Group → 新 Group，再另存 ZIP。

“显示全部”恢复临时隐藏、隔离与部位开关，保留当前血量模拟设置。Group 0 是
基础/原始；0 为基础，已配置血量层级的 Group 使用对应颜色，其他 Group 以红色标为自定义/未映射，不会自动重置。

leg 2、wst 5。测试确认修改一个 Group ID 后只有目标字段字节变化，并且导出的
