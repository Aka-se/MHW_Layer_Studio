# Runtime plugins

## MHWI-VisualControllerExtended

This repository maintains one companion runtime DLL under
`MHWI-VisualControllerExtended`. It provides health-based layer visibility,
per-mod randomized outfit damage, and the integrated `GreatSwordBurst` behavior.

The diagnostic `MHW-GSRecorder` used during development is not a user-facing
requirement and is not distributed here. Stracker's Loader is a third-party
loader and must be downloaded from its original Nexus Mods page.

## 运行插件说明

本仓库维护一个配套运行 DLL：`MHWI-VisualControllerExtended`。血量分层、按模组
随机战损和 `GreatSwordBurst` 均已集成在其中。

开发阶段使用的 `MHW-GSRecorder` 只是诊断采集器，不是用户前置，因此不公开分发。
Stracker's Loader 是第三方加载器，请从原作者页面下载。
